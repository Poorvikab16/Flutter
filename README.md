Flutter App

This is a Flutter project created to develop a cross-platform mobile application. The project uses Dart as the primary language and follows the standard Flutter project structure.

📁 Project Structure

lib/ – Contains the main application code (Dart files)

assets/ – Stores images, icons, and other static resources

pubspec.yaml – Project configuration, dependencies, and assets

android/ – Android-specific files

ios/ – iOS-specific files

test/ – Unit test files

🚀 How to Run the App

Make sure you have Flutter installed. Then run:

flutter pub get
flutter run

📦 Dependencies

All required dependencies are listed in pubspec.yaml.
Run the following command after editing dependencies:

flutter pub get
